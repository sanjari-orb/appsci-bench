# Policy Corpus

Four internal compliance standards a customer-facing contract may be checked against. Each policy
below names only itself and which deal type it applies to; which clauses each one requires, prohibits,
or flags for review is elicited from the stakeholder, not written in these files. A contract is
reviewed against one policy at a time; which policy applies depends on the deal type.

| File | Policy | Applies to |
|---|---|---|
| `vendor_standard.md` | Vendor Contract Standard | General vendor/supplier agreements |
| `ip_protective.md` | IP-Protective Standard | Agreements involving licensing or IP transfer |
| `risk_averse.md` | Risk-Averse Standard | High-liability-exposure engagements |
| `procurement_clean.md` | Procurement Clean Standard | Purchasing/sourcing agreements |
